# AIRA company and brand operating setup

The legal company **AIRA Skill City Private Limited** owns the employee workplace at `airaskillcity.com`. Its Boss company page and company command centre manage people, access, projects, decisions and the four recorded operating brands. The workplace is a company scope, not a fifth brand or a learning programme.

| Top-level brand | Recorded operating scope |
| --- | --- |
| AIRA Startup Skool | Startup programme and admissions workflows; proposed commercial terms remain unapproved. |
| AIRA Skill Studio | Skill programme drafts, product records and delivery work within the Skill Studio division. |
| AIRA Labs | Labs projects and the recorded sub-brands MY SOLAR SOLUTIONS, NTE NAADU, HAPPINOTES, TALKIN LABS, ONSPEAK MENTOR HUB and BGOS. |
| AIRA Career Hub | AIRA careers and the NICEJOBS sub-brand, whose control panel retains applicant, training and workforce controls. |

Labs can navigate to Career Hub to request or manage recruitment through authorized existing controls. This link does not change NiceJobs ownership or duplicate applicant records. BGOS retains its existing product record; its sub-brand record is retained for the confirmed hierarchy.

The explicit group initializer creates a missing OnSpeak Mentor Hub brand as **INACTIVE** and creates missing **GenZ Builder**, **VIVE CODING** (owner-supplied spelling) and **Full Stack Branding Expert** Skill Studio `Program` records as **DRAFT**. It preserves the status of existing matching records and stops on conflicting identities. No duration, capacity, fee, tax treatment, curriculum, owner, written terms or publication approval is inferred. A new GenZ Builder programme draft links to the existing GenZ Builder product draft. The Skill Studio brand page shows recorded programmes and links to the existing AIRA programme editor with its division selected.

The shared programme editor refuses direct activation or resumption of Skill Studio and Startup Skool programmes. A separate evidence-backed publication path is required before any Skill Studio draft becomes active. Programme status alone does not authorize enrolment, fees or payment collection. The existing Career Hub and NiceJobs human approval gates remain in force.

Code deployment alone does not create these database records. The existing `scripts/initialize-group.ts` is the explicit, transactional operator path; it also reconciles other canonical group records, so it must not be run as an unreviewed page action or broad seed. Before running it against any shared target, an authorized operator must verify the database identity, restorable backup, existing brand/product/programme relationships and expected changes. A conflict rolls the transaction back. This change has not been applied to production data or validated on a live domain.

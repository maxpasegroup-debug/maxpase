## Current implementation

- `prisma/schema.prisma` declares `provider = "sqlite"`; Prisma Client and the 31 migrations in `prisma/migrations` are built for SQLite. Replacing `DATABASE_URL` with `postgresql://...` alone cannot migrate or run this application.
- Production environment validation and readiness require an absolute SQLite `file:` URL and inspect SQLite-specific objects. Runtime queries include `sqlite_master` and `json_extract`.
- Financial and automation integrity checks depend on SQLite triggers. Equivalent PostgreSQL constraints/triggers and their failure behavior must be implemented and tested before switching.
- Backup, restore, migration validation, benchmark and many isolation/regression tests use `node:sqlite` or SQLite statements. A passing SQLite suite is not PostgreSQL validation.

# Development Rules

1. MAXPASE GROUP is the parent/group layer.
2. MAXPASE OS is shared operating infrastructure.
3. SIA is the Virtual CEO/intelligence layer.
4. Companies remain independently modeled.
5. AIRA Skill City is a company implementation, not the system root.
6. Group, company, brand, product and project are distinct concepts.
7. Role and permission are distinct concepts.
8. Designation never implies unlimited authority.
9. Organizational scope matters.
10. SIA must use controlled tools rather than arbitrary database access.
11. High-impact actions require explicit authorization/approval.
12. Important actions must be auditable.
13. Do not fabricate business/legal/financial information.
14. Do not introduce speculative complexity without a real requirement.
15. Do not break existing functionality without documenting why.
16. Do not build giant modules before their domain boundaries are clear.
17. Production migrations must be deliberate and controlled.
18. Secrets must never be committed.
19. Tests must validate meaningful behavior.
20. Future phases must preserve backward compatibility unless a documented architectural migration is required.
